IPU — IP, meet you.

Find your IP address, network CIDR, ASN and approximate location. Look up IPv4 or IPv6 with no account or API key.

IPU reports continent, country, region, city, timezone, coordinates and accuracy radius when available. Location is approximate, never a street address. Missing data stays null.

IP lookup for developers and agents

Use GET /1.1.1.1/json for a specific IP, or GET /json for your connection. Without an explicit address, an agent gets its own server's IP.
